# bfsg-scanner

Automated WCAG 2.1 AA accessibility scanning, built on [Playwright](https://playwright.dev) and [axe-core](https://github.com/dequelabs/axe-core), with results mapped to [EN 301 549](https://www.etsi.org/deliver/etsi_en/301500_301599/301549/) and Germany's [BFSG](https://www.gesetze-im-internet.de/bfsg/).

Status: early development. Not yet usable.

## Scope

This project is under active construction. See `docs/adr/` for the architectural decisions behind it.
